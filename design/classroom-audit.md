# 수업용 화면 점검 · 2026-10-29

기존 작업 위에서 입장, 탐색, 주장 선택, 막 통과 실험, 농도 모형, 반박 답안,
결론 합치기, 최종 변론, 클리어 화면을 점검했다. 최신 미션의 농도·질량과
교사 기록 형식은 유지한다.

## 반영

- 입장 문구·교수 대사·자료 카드·버튼·답안 입력의 크기와 대비를 확대했다.
- 입장 및 과제 변화 시 지시문이 가운데 등장하고 왼쪽 위로 축소 이동한다.
  조작을 잠시 멈추고 계속 버튼과 Escape를 제공한다. 동작 줄이기를 지원한다.
- 개념 카드 이름은 ‘개념 1/개념 2’로 표시하고 내부 ID는 유지한다.
- 최종 변론 중 지시문·칠판 질문·실험 자료·교수 대사를 밝게 유지한다.
  카드 목록은 별도 스크롤 영역이고 입력창과 제출 버튼은 화면 안에 둔다.
- 직접 작성한 의미 있는 설명에 감자 키링을 준다. 모드를 바꾸어도 삽입한
  카드 문장이 남아 있으면 보상하지 않는다. 공통 과학 문장을 직접 입력했다는
  이유만으로 카드 사용으로 오인하지 않는다.
- 실제 직접 쓴 구절을 인용해 실험 숫자 해석(W1)과 규칙을 통한 보이지 않는
  세포 내부 설명(W2)을 각각 칭찬한다. 해당 구절과 칭찬의 핵심을 강조한다.
- 작은 화면의 지시문이 막 실험의 분자를 가리지 않도록 시작 위치를 조정했다.

## 검증

- Node 테스트 17/17 통과: 실제 학생 답안, 뒤집힌 설명, 카드 출처, 보상 조건,
  W1/W2 칭찬과 강조, 학생 입력의 HTML 이스케이프.
- 별도 Chrome에서 카드 작성과 직접 작성 두 경로를 처음부터 클리어까지 통과.
- 두 경로에서 클리어 full, 브라우저 예외 0, 기존 실제 Q3 답안 통과.
- 입장 화면: 1024×768, 1280×800, 1366×720, 1920×1080.
- 주장·현미경·최종 변론: 1024×768 및 1280×800. 최종 변론은 1366×720도 점검.
- 최종 변론의 질문·답안 영역 겹침 없음, 입력창 높이 100px 이상,
  제출 버튼 화면 내 배치 확인.
- 일반 동작에서 지시문 이동·축소, 동작 줄이기에서 페이드 확인.
- 직접 작성에서 키링 이미지 로드 및 보상 기록 확인. 카드 작성에서는 미지급.
- 교사 화면에서 카드 사용 구분이 각각 1/0으로 유지됨을 확인.
- 검증은 로컬 저장 모드로 수행했으며 실제 학생 기록 서버로 보내지 않았다.

세부 결과는 classroom-cards-verification.json과 classroom-own-verification.json에 있다.
키링은 내장 image_gen으로 생성했고 원본 프롬프트는 keyring-prompt.json에 보관했다.
