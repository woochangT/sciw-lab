# 서술 실험실 · 미션 01 「감자 속은 얼마나 진할까?」

- 학생: `index.html`
- 교사 히트맵: `teacher.html?class=반코드`

기록은 Google Apps Script 웹 앱(`js/config.js`의 `API_URL`)으로 전송되어 스프레드시트에 저장됩니다.

## 실험실 디자인

학생 화면은 따뜻한 실험실 배경과 교수 표정, 종이 카드와 황동 렌즈를 사용합니다.
`css/laboratory.css`가 기존 화면 스타일 위에 적용되며, `js/scene-art.js`는 장면 그림을 담당합니다.
텍스트·버튼·자료·모형은 HTML/SVG로 동작합니다. `assets/` 폴더도 함께 배포하세요.

현미경의 세포 내부는 밝고, 하나의 얇은 둥근 막이 내부를 감쌉니다.
막 통과 실험은 분자를 끌어 놓거나 물/설탕 실험 버튼으로 조작할 수 있습니다.
농도 슬라이더는 가상 모형의 설정값이며, 실제 감자의 측정 농도를 미리 알려 주지 않습니다.

최신 미션의 `%` 농도와 `g` 질량 변화, 탐색·수집 순서, 두 변론 모드와 판정 기록을 유지합니다.
원본 시안 ZIP, 수정한 세포막 시안과 생성 프롬프트는 `design/`에 있습니다.

마법 현미경은 빛나는 수정과 별빛 효과로 개념 모형을 보여 줍니다. 실제 분자 관찰 영상이 아닙니다.
관찰창은 모서리가 둥근 직사각형이며, 작은 둥근 세포 바깥에 충분한 공간을 둡니다.
교수 옆의 세로 콧대 게이지는 반박을 통과할 때 줄어들며 답안 작성 중에도 표시됩니다.

## 판정 회귀 테스트

`node --test tests/judge.test.cjs`로 실행합니다. ‘진하기’를 ‘진하다’로 오인하던 문제와
두 실제 학생 답안의 정답 인정, 방향이 뒤집힌 오답 구분을 확인합니다.

## 수업용 노트북 화면

`css/classroom.css`는 입장·탐색·현미경·답안·클리어 화면의 글자와 조작부를 확대합니다.
새 지시문은 가운데에 크게 등장한 뒤 왼쪽 위의 해당 지시문으로 이동합니다.
계속 버튼으로 즉시 이동할 수 있고, 동작 줄이기 설정에서는 짧은 페이드로 바뀝니다.
학생에게는 내부 식별자 M1/M2 대신 ‘개념 1/개념 2’를 표시합니다.

최종 답안 작성 중에는 지시문, 주제 질문, 실험 자료, 교수의 말을 밝게 유지합니다.
카드 목록만 따로 스크롤하며, 답안과 제출 버튼은 계속 보이도록 배치합니다.
카드 문장을 실제로 넣었는지 별도로 추적하므로 같은 과학 문장을 직접 쓴 것만으로
카드를 사용했다고 처리하지 않습니다. 카드에서 넣은 문장이 남아 있으면 모드를
바꾸더라도 직접 쓴 답안으로 보상하지 않습니다.

‘내 말로만 쓰기’에서 카드 문장 없이 의미 있는 설명을 직접 쓰면 클리어 화면에
교수님의 감자 키링을 표시합니다. 빈 답안과 판독 불가 답안에는 보상하지 않습니다.
키링 원본은 `assets/potato-keyring.png`, 생성 프롬프트는 `design/keyring-prompt.json`입니다.
칭찬은 학생이 직접 쓴 문장을 인용하며, 숫자와 물의 드나듦을 연결한 부분(W1),
물이 움직이는 규칙으로 세포 안팎의 농도를 설명한 부분(W2)을 각각 강조합니다.

`node --test tests/judge.test.cjs tests/learning.test.cjs`로 판정·출처·보상·칭찬 검사를 실행합니다.
