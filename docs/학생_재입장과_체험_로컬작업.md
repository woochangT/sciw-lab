# 학생 재입장과 체험·심사 입장

## 작업 기준과 범위

2026-11-10 `front-end`의 `40dde5e`에서 로컬 작업을 시작하고, 반영 전에 최신 `00f0fbe` 위로 변경을 재적용했다. 최신 교사 비교 화면·실패 판정 재시도·대화 연결 정보를 보존했다. 사용자 승인으로 기존 기록 Apps Script를 버전 11로 업데이트했다. 기록 주소와 연결 시트는 기존 그대로다. `main`에는 이번 변경을 합치지 않는다.

수정 범위는 두 게임의 입장, 진행 상태 저장·복원, 체험 모드의 기록 차단이다. 미션 대사·그림·판정 기준과 교사 화면은 유지한다. 기존 데이터 열을 추가하거나 이전 플레이를 삭제하지 않는다.

## 동작

- 학년·반·번호·미션이 같은 최신 플레이를 기록 서버에서 조회한다.
- 기록이 있으면 **이어 하기 / 처음부터 새로 하기 / 돌아가기**를 표시한다.
- 이어 하기는 같은 sessionId를 사용한다. 새로 하기는 별도 sessionId를 만들어 이전 플레이를 보존한다.
- 복원용 정보가 없는 이전 버전의 기록도 입장을 막지 않는다. 해당 기록의 이어 하기는 비활성화하고 새로 하기를 제공한다.
- 체험·심사 입장은 학년·반·번호가 필요 없다. 학생 세션·시도·대화·초안·복원 상태를 저장하지 않고, 브라우저 대기열이나 기존 미전송 기록도 재전송하지 않는다.
- AI 평가는 기존 판정 주소와 기준을 사용한다. 체험이라고 AI 요청 자체가 없어지는 것은 아니며, 평가 서버의 호출 상한은 그대로 적용된다.

## 서버 저장과 복원

기존 세션 payload에 `checkpoint`, `checkpointSavedAt`을 추가한다. `checkpoint`는 버전 식별자 `student-resume-v1`, 미션, 복원 지점, 카드와 통과 상태, 작성 중인 글 등을 포함한다. DOM·타이머·애니메이션 좌표·함수는 저장하지 않는다. 관찰/연출 도중 나가면 해당 활동의 시작 지점에서 재개하며, 완료한 단서·통과한 질문·작성한 설명은 보존한다.

기록용 Apps Script에 `findStudentSession` POST를 추가했다. 지정한 학년·반·번호·미션의 최신 세션 식별자와 복원 정보만 반환하며, 교사용 학급 목록이나 전체 대화 이력을 반환하지 않는다. 입력 범위는 기존 학년 1~3·반 1~99, 출석번호 1~999다. 학생 조회용 새 식별 방식이나 본인 인증은 추가하지 않았으므로 학년·반·번호를 아는 사람이 해당 기록을 이어 할 수 있다는 현재 입장 방식의 한계가 있다. 팀에서 학생 식별·본인 인증 방식을 강화할 경우 이 조회 경로도 함께 검토해야 한다.

운영 **기록용** 프로젝트의 현재 코드가 최신 `00f0fbe`와 일치함을 확인하고 `Code.gs`의 학생 조회·복원 정보 검증만 추가했다. `Rejudge.gs`, `Evaluators.gs`, 속성·키·공유 범위는 수정하지 않았다. 기존 웹 앱 주소에 버전 11을 배포했다. 별도 AI 평가 프로젝트의 코드·속성·배포는 변경하지 않았다. 학생 조회 API가 없는 이전 서버에서는 원인을 안내하고 체험 입장을 제공하며, 조회 실패를 기록 없음으로 처리하거나 이전 판을 덮어쓰지 않는다.

## 로컬 실행

저장소 루트에서 실행한다.

```sh
node tools/session-preview.cjs
```

주소는 `http://127.0.0.1:8796/`다. `SCIW_PREVIEW_PORT`로 포트를 바꿀 수 있다.

이 서버는 실제 `apps-script/Code.gs`를 Node VM에서 실행한다. Sheets 저장소만 로컬 파일 `.local/session-preview/sheets.json`으로 대체하므로 **브라우저 저장소를 지워도 서버 파일에 저장한 플레이는 남는다.** 기존 운영 시트에는 요청하지 않는다. 게임의 기록 주소는 응답 시에만 `/api/records`로 바꾸며 원본 `config.js`는 유지한다. 서버를 재시작해도 파일을 다시 읽는다. 기록 API는 같은 로컬 화면의 요청만 받으며 숨김 파일과 서버 데이터 파일은 정적으로 제공하지 않는다.

감자 미션의 기존 기록 서버 겸용 LLM 요청은 이 로컬 기록 서버가 제공하지 않으므로 해당 미션의 기존 규칙 대체 경로를 사용한다. 강철솜은 기존 별도 AI 평가 서버로 연결된다. 운영의 두 미션 판정 코드는 변경하지 않았다.

실행 중인 로컬 서버를 종료한 경우 같은 명령으로 다시 켠다. 소스를 고치면 브라우저를 새로 고치고, `apps-script/Code.gs`를 고쳤으면 로컬 서버도 재시작한다. 작업 데이터 `.local/`는 Git에서 제외되어 있다.
