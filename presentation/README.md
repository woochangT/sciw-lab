# 최종 발표 화면

2026 SNU TEIC AIED 챌린지 최종 발표(서술 실험실)용 HTML 발표 화면이다. 설명 장면은 실험 노트 디자인이고, 시연 장면은 실제 게임(`?demo=1|2|3`)과 교사 화면(`teacher.html`, Google 시트의 실제 기록)을 화면 전체에 띄운다.

## 여는 법

게임과 같은 출처에서 열어야 시연 장면이 붙는다. 저장소 루트에서

```
python -m http.server 8765
```

을 실행하고 `http://127.0.0.1:8765/presentation/` 를 연다. (배포 주소에 올라가면 `…/presentation/`으로 열 수 있다.)

교사 화면(12장)은 시트 API가 허용한 주소에서 열어야 실제 기록이 보인다. 로컬 `http.server`에서는 게임 시연(9~11장)만 되고, 교사 화면은 시트에 연결되지 않는다. 발표는 GitHub Pages 주소 `https://woochangt.github.io/sciw-lab/presentation/`에서 연다.

### 발표 전에 할 일

1. 발표 노트북에서 위 주소를 열고 12장으로 가서 교사 암호를 넣는다. 로그인은 그 브라우저 탭에서 8시간 유지되므로, 같은 탭에서 1장으로 돌아가 발표한다. 탭을 새로 열면 다시 넣어야 한다.
2. 12장에서 3학년 13반 `수업 준비`의 **학급 재분석**을 한 번 눌러 둔다(AI 호출, 수십 초). 결과는 그 브라우저에 저장되어 발표 중에는 '수업 참고' 문구가 바로 보인다.
3. '장면 처음부터'로 12장을 다시 불러 안내가 처음(학급별 성취도)부터 시작하는지 확인한다.

## 조작

| 키 | 동작 |
| --- | --- |
| → · Space · PageDown | 다음 (한 장 안의 단계를 하나씩 드러낸 뒤 다음 장) |
| ← · PageUp | 이전 |
| F | 전체 화면 |
| 숫자 + Enter | 그 장으로 이동 |

### 시연 장면(9~12장)

보여 줄 기능까지만 진행되고, 끝나면 오른쪽 아래에 **다음 장 ▸** 표시가 뜬다. 그때 다음 키를 누르거나 화면 아무 데나 누르면 다음 장으로 간다. 그 전에는 다음 장으로 넘어가지 않는다.

| 장 | 보여 줄 기능 | 끝나는 지점 |
| --- | --- | --- |
| 9 시연 1 | 교수의 오독 → 뒷면 고쳐 쓰기(종속 변인 번역) | 꼬투리 ① 통과(빨간 글씨가 지워지고 콧대가 내려감) |
| 10 시연 2 | 마법 현미경(모형화) → 뒷면 쓰기 | 현미경 단서를 얻고, 꼬투리 ③ 뒷면을 고쳐 써서 통과 |
| 11 시연 3 | 최종 답 → 처음/지금 비교·형광펜 | 선생님께 제출 |
| 12 교사 화면 | 학급별 성취도 → 3학년 13반 수업 준비(다음 수업 질문) → 해당 학생 번호 → 그 학생의 보완 칸 → 판정 이유·인용 → 수업 준비의 함께 읽을 학생 답안 | 함께 읽을 답안까지 봄 |

- 게임 장면(9~11)에서 리모컨의 다음(PageDown)은 교수 대사 넘기기로 쓰인다. 현미경·불꽃·제출 버튼은 마우스로 누른다.
- 교사 화면(12)에서는 노란 테두리로 가리킨 버튼만 누를 수 있다. 다음 키를 누르면 가리킨 버튼을 대신 누르거나, 읽는 단계는 넘긴다(`tour-teacher.js`). 마우스로는 노란 테두리 안이나 옆의 '다음 ▸'을 누른다. 가리킬 학생은 그 반에서 가장 많이 빠진 고리(보완 1)의 해당 학생을 자동으로 고른다. 발표용 반은 `tour-teacher.js`의 `CLASS_KEYS` 첫 항목(`g:3:r:13`)이고, 그 반이 없으면 예시 수업의 3학년 4반으로 이어진다(시트가 끊기면 자료를 '예시 수업'으로 바꾸면 된다). 암호 화면이 떠 있는 동안에는 안내가 기다린다.
- 막히면 Esc로 게임에서 빠져나와 → 로 넘길 수 있다(교사 화면 안내 중에는 Esc가 막혀 있다). 오른쪽 아래 구석에 마우스를 올리면 '장면 처음부터' 버튼이 보인다.
