교수는 반박하지 않고 빈틈을 조명한다. 교수의 설명 카드(개념 1·2)는 주지 않는다. 학생이 조작해서 알아낸 한 줄이 카드의 뒷면이 된다. 화면 안내문은 쓰지 않는다. 할 일은 교수 대사와 깜빡임(깜빡인 뒤 빛 테두리와 별 반짝임)으로 알린다. 할 일이 바뀌는 대사는 화면 가운데에 크게 떠서 꼬리가 교수 입까지 이어지고, 읽고 나면(또는 누르면) 머리 위로 옮겨 가며 작아진다. 교수가 할 말이 아닌 안내(콧대를 눌러 주자, 돋보기 쓰는 법, 현미경이 모형이라는 것)는 게임 시스템의 말로 따로 보인다. 또 20초 동안 조작이 없으면 교수가 한마디 한다. 콧대 단계는 미션 01(감자)과 같이 교수 그림으로 보인다(3~4 거만, 2 턱 괴기, 1 놀람, 0 웃음). 코도 실제로 줄어든다(같은 그림의 코끝을 뿌리 쪽으로 밀어 넣으며 두께를 맞춤). 4는 원래의 긴 코, 0은 보통 사람 코 길이다. 콧대 게이지는 처음에 보이지 않는다. 2에서 시작해 드러내기 단계가 시작되면 교수 얼굴로 다가가 게이지가 나타나며 4로 솟고, 꼬투리를 풀 때마다 얼굴로 다가가 코가 한 단계씩 줄어들며, 완전 클리어하면 0이 된다. 옆 게이지에는 남은 칸(예: 3 / 4)이 보인다.

## 튜토리얼

시작 화면의 '튜토리얼' 버튼은 `tutorial.html`을 화면 전체에 띄운다(iframe). 창이 따로라 본 게임 상태와 섞이지 않고, 입력한 반·번호도 그대로 남는다. 대본과 수치는 `missions/tutorial02.js`, 흐름은 `js/tutorial02.js`에 있고 화면 부품은 본 게임 엔진(`SCIW_ENGINE02`)을 그대로 쓴다.

- **소재:** 실 전화기. 실을 잡으면 건너편 컵의 소리가 60 dB에서 20 dB로 준다(모형용 예시 값). 강철솜의 숫자와 산소·질량은 넣지 않고, 마개 여닫기와 최종 답안 기능도 미리 보여 주지 않는다.
- **흐름:** 실험실의 규칙 → 숫자는 측정기도 읽는다 → 실 잡아 보기 → 칠판에 올리기 → 제멋대로 읽기 → 현미경 다녀오기 → 뒷면 채우기 → 콧대 꺾기 → 오늘의 사건으로. 본 게임과 같은 손놀림(대고 있기, 획득, 카드 끌어 놓기, 현미경, 돋보기)을 실제로 해야 넘어간다.
- **판정:** 뒷면은 보기 4개 중 고른다. AI 평가를 호출하지 않아 호출 상한을 쓰지 않는다.
- **기록:** 튜토리얼 안의 조작은 저장하지 않는다(`api.js`를 싣지 않는다). 본 게임 세션의 `tutorial` 값에 시청 여부만 남는다(`none` · `skipped` · `done`). 시트에서는 extra 열에 모인다. 튜토리얼을 본 학생의 처음 생각은 진단할 때 구분해 읽는다.

## 판정과 기록

- 처음 생각·Q1·Q2·Q3·최종 글과 결과 하이라이트는 모두 API로 평가한다. 규칙 판정과 모드 전환은 제거했다. API 실패 시 입력을 보존하고 재시도한다.
- `hintLevel`은 학생이 실제로 펼쳐 본 강의 노트의 쪽수다(0이면 펼치지 않음). Q1~Q3은 "…라는 것은 ___라는 뜻이다" 답 틀로 실험 B의 불변, 실험 A의 증가, 산소만 줄어든 관찰의 뜻을 묻는다. 기준은 [평가 루브릭 v1.2](../강철솜_미션02_연결과_직접서술_평가루브릭.md)이며, 공통 구현은 `js/rubric02.js`다.
- 평가 서버에는 루브릭 1.2를 배포 버전 4로 반영했다(2026-11-02). 실제 AI 점검 결과는 [AI 평가 로컬 실험과 이전](../AI%20평가%20로컬%20실험과%20이전.md)에 있다.
- 기록용 `API_URL`은 기존 검증된 팀 Apps Script 주소를 유지한다. 평가 요청은 별도 `JUDGE_API_URL`을 사용하며 두 주소를 혼용하지 않는다. 기존 미션별 저장·세션 재개·재전송 코드는 유지한다.
- **2026-11-02 평가 서버를 배포하고 `JUDGE_API_URL`에 연결했다.** 정적 화면에서도 배포된 평가 서버를 호출한다. 키는 Apps Script 서버 속성에만 저장한다. 기본 호출 상한은 전체 하루 300회·분당 30회다.
- 저장소 루트의 `node tools/m02-local-server.cjs`로 AI 실험을 실행한다. 같은 게임 소스의 실험 복사본은 두 미션과 교사 화면의 운영 기록 주소를 비워 실제 팀 시트에 기록하지 않는다. 키는 사용자가 `.local/openai-api-key`에 직접 넣는다.
- 실행 방법과 이전 절차는 [AI 평가 로컬 실험과 이전](../AI%20평가%20로컬%20실험과%20이전.md)에 있다. `apps-script/m02-evaluator/Code.gs`는 별도 평가 프로젝트용이다. 기존 운영 `apps-script/Code.gs`에 덮어쓰지 않는다.
- 인트로·미션 01·공용 교사 화면과 기존 기록 백엔드는 이번 변경 범위에 포함하지 않는다.
