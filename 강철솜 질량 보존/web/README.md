# 서술 실험실 · 미션 02 「늘어난 강철솜」

- 학생 화면: `index.html` (정적 파일이라 아무 정적 서버로 열면 된다. 예: `python3 -m http.server 8792`)
- 미션 01(`감자 삼투/web`)과 파일을 공유하지 않는 독립 폴더다. `js/api.js`와 그림 두 장(`assets/`)만 미션 01에서 복사했다.

## 무엇이 들어 있나

PRD 「미션 02 강철솜 질량 보존」(2026-10-30 초안)의 한 판 흐름과 보완안 1~5를 반영하고, 글 대신 직접 조작으로 알아내도록 바꾼 판이다. 중3 플레이테스트 피드백(TARE 장면, 분자 쌍, 반짝이는 조작 대상, 저울 위 액정)까지 반영했다.

| 단계 | 내용 |
| --- | --- |
| 탐색 | 빈 접시를 TARE로 0.0 g 맞춘 뒤 강철솜을 올리는 장면으로 시작한다. 장치 A는 불꽃 막대를 끌어서 강철솜에 대고 있는 동안 타고 저울이 그 자리에서 오른다. 장치 B(마개 막은 플라스크)는 집게를 전원 장치 빨간 단자에 끌어다 물리면 전류가 흐르는 동안 탄다. 타는 동안에만 강철솜 위로 불꽃이 일렁이고 불씨·연기, 전극 사이 전기 불꽃이 보인다. 실험 노트는 없앴다. 저울은 전자저울 모양이고, 무엇을 재는지는 저울 앞 테이프에, 전·후 기록은 종이쪽지에 남는다. 단서 카드는 도장이 찍히는 획득 연출과 함께 모인다 |
| 주장 | 교수가 먼저 묻고 학생이 처음 생각을 직접 쓴다(보완안 1) → 까닭 고르기 + 근거 카드 두 장 |
| 반박 | 현미경 조사 → 새 단서 → 교수 말 반박 → 한 줄 이유를 세 번. 산소·질소는 두 원자짜리 분자로 떠다니고, 막힘이면 집게를 빨간 단자에 물려 둔 동안, 열림이면 불꽃을 강철솜에 대고 있는 동안 산소 분자가 하나씩 철에 붙는다. 저울 숫자는 그림 속 저울 몸체 위에 뜬다. 저울과 '점선 안 원자'는 원자가 점선을 넘는 순간 바뀐다. 실험이 끝나면 단서 카드가 도장과 함께 획득된다. 반박 라운드에 들어가면 실험대와 수집함이 걷히고, 커진 말풍선과 단서 줄만 남는 반박 화면으로 넘어간다(라운드가 끝나면 실험실로 돌아온다). 교수가 "혹시 ~ 아니겠나?" 하고 추측을 늘어놓으면 색이 들어간 곳 중 틀린 말에 단서 카드를 끌어다 댄다(시간 제한 없음, 맞는 말도 섞여 있음). 맞히면 왜 뒤집히는지 한 줄 쓰고 그 한 줄이 결론 카드가 된다. 2·3라운드는 앞에서 모은 단서도 쓸 수 있다고 교수가 먼저 말한다 |
| 결론 합치기 | 결론 ①·③을 칠판에 올리면 두 실험의 작은 장면이 나란히 움직인다(막힘: 산소가 안에서 옮겨 가고 150.0 g 그대로 / 열림: 바깥 산소가 붙으며 2.0 → 2.5 g). 탭할 때까지 남아 있다 |
| 변론 | 카드 나누기(분필 칸 "실험과 현미경에서 본 것 / 그게 뜻하는 것 / 그래서 일어난 일", 보완안 3, 카드 8장) → 답안 짜기, 첫 제출이 부족하면 교수가 "부족한 곳이 있네, 어디를 꼬투리 잡을 것 같나?"라고 묻고 학생이 빠진 곳을 고른다(보완안 5), 잠긴 강의 노트(글 구조 힌트 1·2단계), '혼자 힘으로 설명하기'(카드 대신 단서 그림만 보이고 붙여넣기는 막는다)와 키링 |
| 클리어 | 처음 생각과 마지막 답 비교, 새로 생긴 연결 형광펜, 직접 쓴 부분과 카드 문장 밑줄 구분, 학생 문장 인용 칭찬 |

교수의 설명 카드(개념 1·2)는 주지 않는다. 학생이 조작해서 알아낸 한 줄이 결론 카드가 된다. 화면 안내문은 쓰지 않는다. 할 일은 교수 대사와 깜빡임(깜빡인 뒤 빛 테두리와 별 반짝임)으로 알리고, 20초 동안 조작이 없으면 교수가 한마디 한다. 반박 화면에서는 단서 카드가 들썩인다. 콧대 단계는 미션 01(감자)과 같이 교수 그림으로 보인다(3~4 거만, 2 턱 괴기, 1 놀람, 0 웃음). 코도 실제로 줄어든다(같은 그림의 코끝을 뿌리 쪽으로 밀어 넣으며 두께를 맞춤). 4는 원래의 긴 코, 0은 보통 사람 코 길이다. 2에서 시작해 반박이 시작되면 교수 얼굴로 다가가 4로 솟고, 반박을 통과할 때마다 얼굴로 다가가 코가 한 단계씩 줄어들며, 완전 클리어하면 0이 된다. 옆 게이지에는 남은 칸(예: 3 / 4)이 보인다.

## 판정과 기록

- 판정은 키워드 규칙만 쓴다(`js/judge02.js`). LLM 판정은 꺼 두었다(`js/config.js`의 `USE_LLM: false`).
- 기록은 지금 로컬 모드다(`API_URL: ''`). 미션 01과 같은 Sessions·Attempts 형식으로 브라우저 localStorage에 쌓인다.
- `apps-script/Code.gs`는 미션 02 기록(최종 판정 열 finalDA·finalDB·finalW1a·finalW1b 등, 머리글에 없는 값은 `extra` 열)과 미션별 LLM 판정 설정을 받도록 고쳤다. 연결 순서는 `../브랜치 공유와 Apps Script 연결.md`에 있다.
- LLM 판정용 상황 설명과 오류 목록은 `missions/mission02.js`의 `llm…` 항목에 있다. 게임에서 판정을 부르는 코드는 아직 넣지 않았다.
- 교사 히트맵은 이번 범위에서 뺐다.
