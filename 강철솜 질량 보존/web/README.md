## 무엇이 들어 있나

PRD 「미션 02 강철솜 질량 보존」(2026-10-30 초안)의 한 판 흐름과 보완안 1~5를 반영하고, 글 대신 직접 조작으로 알아내도록 바꾼 판이다. 중3 플레이테스트 피드백(TARE 장면, 분자 쌍, 반짝이는 조작 대상, 저울 위 액정)까지 반영했다.

| 단계 | 내용 |
| --- | --- |
| 탐색 | 빈 접시를 TARE로 0.0 g 맞춘 뒤 강철솜을 올리는 장면으로 시작한다. 장치 A는 불꽃 막대를 끌어서 강철솜에 대고 있는 동안 타고 저울이 그 자리에서 오른다. 장치 B(마개 막은 플라스크)는 집게를 전원 장치 빨간 단자에 끌어다 물리면 전류가 흐르는 동안 탄다. 타는 동안에만 강철솜 위로 불꽃이 일렁이고 불씨·연기, 전극 사이 전기 불꽃이 보인다. 실험 노트는 없앴다. 저울은 전자저울 모양이고, 무엇을 재는지는 저울 앞 테이프에, 전·후 기록은 종이쪽지에 남는다. 단서 카드는 조작한 장치 바로 오른편에 뜨는 패널에서 학생이 '획득'을 눌러야 수집함으로 간다(그동안 실험 장면은 그대로 보인다) |
| 주장 | 교수가 먼저 묻고 학생이 처음 생각을 칠판 바로 아래 칸에 직접 쓴다(보완안 1) → 까닭 고르기 + 근거 카드 두 장(빈칸에 "실험 결과를 근거로!") → 교수가 "실험 결과만 가지고 어떻게 그 주장에 도달했나"를 짚으며 다음 단계로 넘어가는 이유를 말한다 |
| 드러내기 | 현미경 조사 → 새 단서 → 교수 말 반박 → 한 줄 이유를 세 번. 산소·질소는 두 원자짜리 분자로 떠다니고, 막힘이면 집게를 빨간 단자에 물려 둔 동안, 열림이면 불꽃을 강철솜에 대고 있는 동안 산소 분자가 하나씩 철에 붙는다. 저울 숫자는 그림 속 저울 몸체 위에 뜨고, 변화 메모("← 무게 변화 없음" 등)는 숫자 바로 오른편에 붙는다. 저울과 '점선 안 원자'는 원자가 점선을 넘는 순간 바뀐다. 막힘 장면에서는 플라스크 바깥 공기(산소·질소)도 떠다니고, 결합한 산소는 모두 플라스크 안쪽에 놓인다. 마개를 누르면 마개가 뽑혀 바닥에 떨어지고 플라스크가 사라지며 점선 범위가 줄어들어 열림 장면으로 이어진다(바깥 공기는 그대로 열림 장면의 공기가 된다). 실험이 끝나면 단서 패널이 화면 가운데에 크게 떴다가 우측 하단으로 줄어들며 옮겨 가고, 거기서 '획득'을 눌러 단서를 얻는다. 누르기 전에는 '다시 하기'로 다시 볼 수 있다. 반박 라운드에 들어가면 실험대와 수집함이 걷히고, 커진 말풍선과 단서 줄만 남는 반박 화면으로 넘어간다(라운드가 끝나면 실험실로 돌아온다). 교수가 "혹시 ~ 아니겠나?" 하고 추측을 늘어놓으면 색이 들어간 곳 중 틀린 말에 단서 카드를 끌어다 댄다(시간 제한 없음, 맞는 말도 섞여 있음). 맞히면 왜 뒤집히는지 한 줄 쓰고 그 한 줄이 드러내기 카드가 된다. 2·3라운드는 앞에서 모은 단서도 쓸 수 있다고 말풍선 아래에 시스템의 말로 알려 준다 |
| 드러내기 카드 합치기 | 드러내기 ①·③을 칠판에 올리면 두 실험의 작은 장면이 나란히 움직인다(막힘: 산소가 안에서 옮겨 가고 150.0 g 그대로 / 열림: 바깥 산소가 붙으며 2.0 → 2.5 g). 탭할 때까지 남아 있다 |
| 완전한 설명 | 카드 나누기(분필 칸 "실험과 현미경에서 본 것 / 내가 더 드러낸 것 / 그래서 도출한 주장", 보완안 3, 카드 8장) → 답안 짜기, 첫 제출이 부족하면 교수가 "부족한 곳이 있네, 어디를 꼬투리 잡을 것 같나?"라고 묻고 학생이 빠진 곳을 고른다(보완안 5), 잠긴 강의 노트(글 구조 힌트 1·2단계), '혼자 힘으로 설명하기'(카드 대신 단서 그림만 보이고 붙여넣기는 막는다)와 키링 |
| 클리어 | 처음 생각과 마지막 답 비교, 새로 생긴 연결 형광펜, 직접 쓴 부분과 카드 문장 밑줄 구분, 학생 문장 인용 칭찬. 혼자 힘으로 완전 클리어하면 강철솜 키링을 받고, 받지 못하면 키링 실루엣과 "다음엔 이걸 줄 수도 있겠군."이 나온다 |

교수의 설명 카드(개념 1·2)는 주지 않는다. 학생이 조작해서 알아낸 한 줄이 드러내기 카드가 된다. 화면 안내문은 쓰지 않는다. 할 일은 교수 대사와 깜빡임(깜빡인 뒤 빛 테두리와 별 반짝임)으로 알린다. 할 일이 바뀌는 대사는 화면 가운데에 크게 떠서 꼬리가 교수 입까지 이어지고, 읽고 나면(또는 누르면) 머리 위로 옮겨 가며 작아진다. 교수가 할 말이 아닌 안내(콧대를 눌러 주자, 앞서 수집한 단서를 써도 돼)는 게임 시스템의 말로 따로 보인다. 또 20초 동안 조작이 없으면 교수가 한마디 한다. 반박 화면에서는 단서 카드가 들썩인다. 콧대 단계는 미션 01(감자)과 같이 교수 그림으로 보인다(3~4 거만, 2 턱 괴기, 1 놀람, 0 웃음). 코도 실제로 줄어든다(같은 그림의 코끝을 뿌리 쪽으로 밀어 넣으며 두께를 맞춤). 4는 원래의 긴 코, 0은 보통 사람 코 길이다. 콧대 게이지는 처음에 보이지 않는다. 2에서 시작해 드러내기 단계가 시작되면 교수 얼굴로 다가가 게이지가 나타나며 4로 솟고, 반박을 통과할 때마다 얼굴로 다가가 코가 한 단계씩 줄어들며, 완전 클리어하면 0이 된다. 옆 게이지에는 남은 칸(예: 3 / 4)이 보인다.

## 판정과 기록

- 처음 생각·Q1·Q2·Q3·최종 글과 결과 하이라이트는 모두 API로 평가한다. 규칙 판정과 모드 전환은 제거했다. API 실패 시 입력을 보존하고 재시도한다.
- Q1은 닫힌 플라스크 전체 질량이 일정한 이유를 묻는다. 기준은 [평가 루브릭 v1.1](../강철솜_미션02_연결과_직접서술_평가루브릭.md)이며, 공통 구현은 `js/rubric02.js`다.
- 기록용 `API_URL`은 기존 검증된 팀 Apps Script 주소를 유지한다. 평가 요청은 별도 `JUDGE_API_URL`을 사용하며 두 주소를 혼용하지 않는다. 기존 미션별 저장·세션 재개·재전송 코드는 유지한다.
- **2026-11-02 평가 서버를 배포하고 `JUDGE_API_URL`에 연결했다.** 정적 화면에서도 배포된 평가 서버를 호출한다. 키는 Apps Script 서버 속성에만 저장한다. 기본 호출 상한은 전체 하루 300회·분당 30회다.
- 저장소 루트의 `node tools/m02-local-server.cjs`로 AI 실험을 실행한다. 같은 게임 소스의 실험 복사본은 두 미션과 교사 화면의 운영 기록 주소를 비워 실제 팀 시트에 기록하지 않는다. 키는 사용자가 `.local/openai-api-key`에 직접 넣는다.
- 실행 방법과 이전 절차는 [AI 평가 로컬 실험과 이전](../AI%20평가%20로컬%20실험과%20이전.md)에 있다. `apps-script/m02-evaluator/Code.gs`는 별도 평가 프로젝트용이다. 기존 운영 `apps-script/Code.gs`에 덮어쓰지 않는다.
- 인트로·미션 01·공용 교사 화면과 기존 기록 백엔드는 이번 변경 범위에 포함하지 않는다.
