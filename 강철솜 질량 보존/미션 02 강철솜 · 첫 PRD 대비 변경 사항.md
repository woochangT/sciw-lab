# 미션 02 강철솜 · 첫 PRD 대비 변경 사항

2026-10-31

한 판의 흐름과 판정 기준은 첫 PRD를 그대로 따르고, 학생이 손으로 해 보는 방식과 화면의 말을 변경했습니다. 비교 기준은 [서술 실험실 PRD — 미션 02 강철솜 질량 보존.md](%EC%84%9C%EC%88%A0%20%EC%8B%A4%ED%97%98%EC%8B%A4%20PRD%20%E2%80%94%20%EB%AF%B8%EC%85%98%2002%20%EA%B0%95%EC%B2%A0%EC%86%9C%20%EC%A7%88%EB%9F%89%20%EB%B3%B4%EC%A1%B4.md)(2026-10-30 초안)와 [`design/`](design/)의 그림 두 장(현미경 화면 배치, 한 판 흐름도)입니다. 현재 상태는 이 저장소 `front-end` 브랜치의 [`web/`](web/) 기준입니다.

바뀐 방향은 세 가지로 요약됩니다.

1. 버튼을 누르면 저절로 일어나던 실험을 학생이 직접 조작해 알아내도록 바꿨습니다.
2. 설명하는 화면 글과 C·D·W 같은 용어를 화면에서 걷어 내고, 교수의 말과 장면으로 대신했습니다.
3. 반박 단계를 고르기 문제에서, 교수의 추측을 단서로 깨는 탐정 게임 구조로 바꿨습니다.

| 영역 | 첫 PRD | 현재 |
| --- | --- | --- |
| 점화 | [불 붙이기]·[전기 점화] 버튼, 2초 자동 | 불꽃 막대를 대고 있는 동안만 탐, 집게를 단자에 물려 점화 |
| 저울 | 이름 붙은 저울 창 | 전자저울, 시작 시 TARE 장면 |
| 단서 | 장치 옆 말풍선 카드 + [단서 수집] | 획득 연출, 증거 모양 카드(사진·슬라이드·쪽지) |
| 모형 카드 | M1·M2 원형 렌즈 카드 | 없음, 현미경 관찰 슬라이드 카드로 대체 |
| 반박 | 미니 퀘스트 3개(고르기 → 서술) | 교수 추측 3라운드, 단서로 반박 후 한 줄 답 |
| 안내 | 깜빡임, 동사 칩, 회색 힌트 줄, 좌상단 쪽지 | 깜빡임과 별 반짝임, 교수의 한마디, 쪽지 없음 |
| 결론 합치기 | 질량 막대 두 개 + 요약 한 줄 | 두 실험의 작은 장면, 요약 문구 없음 |
| 분류 칸 | 주장(C)·증거(D)·연결(W) | 실험과 현미경에서 본 것 · 그게 뜻하는 것 · 그래서 일어난 일 |
| 판정·기록 | LLM + 키워드, 팀 시트, 교사 히트맵 | 키워드만, 브라우저 안 기록, 히트맵 없음 |

## 그대로 유지한 것

한 판의 흐름(탐색 → 주장 → 반박 → 변론 → 클리어)과 단계 트랙 네 칸은 PRD와 같습니다. 콧대 교수와 콧대 게이지 4칸, 마개를 막은 실험 B와 열어 둔 실험 A의 쌍, 현미경 원자 모형과 "저울이 재는 범위" 점선도 그대로 씁니다.

변론의 두 단계(카드 분류 → 답안 짜기)도 유지했습니다. 강의 노트 힌트는 첫 제출 전에는 잠겨 있고, 답안 짜기 90초 경과·20자 미만 또는 60초 무입력이면 열립니다. '혼자 힘으로 설명하기'로 완전 클리어하면 키링을 받는 규칙, 클리어 화면의 처음 답·마지막 답 비교도 같습니다.

판정 요소 일곱 개(C, D-A, D-B, W1a, W1b, W2a, W2b)와 두 통과 경로, 빠진 요소를 묻는 순서(W2 → W1b → W1a → D-B → D-A → C), 최대 3회 제출도 PRD 기준을 따릅니다.

## 탐색: 버튼 대신 직접 조작

점화는 버튼에서 직접 조작으로 바꿨습니다. PRD에서는 장치 받침대의 [불 붙이기]·[전기 점화]를 누르면 2초 동안 저절로 탔습니다. 지금은 불꽃 막대를 끌어다 강철솜에 대고 있는 동안만 타고, 떼면 멈춥니다. 실험 B는 전원 장치의 집게를 끌어 빨간 단자에 물려야 불이 붙습니다.

저울은 사실적인 전자저울로 바꿨습니다. 시작하면 빈 접시가 올라간 저울(31.4 g)에서 TARE를 눌러 0.0 g을 만들고, 강철솜을 올려 2.0 g이 되는 장면이 나옵니다. PRD에 없던 장면으로, 표의 2.0 g이 접시 무게를 뺀 값이라는 점을 보여 주려고 넣었습니다.

저울 이름은 PRD의 "접시 위 강철솜(남은 물질)"·"플라스크 전체"에서 "실험 A · 강철솜"·"실험 B · 플라스크 전체" 테이프로 바꿨습니다. 칠판 질문의 "실험 A"가 어느 장치인지 바로 알 수 있게 하려는 것입니다. 변화량 표기(2.0 → 2.5 g, 150.0 → 150.0 g)는 저울 아래 종이 쪽지로 남깁니다.

## 단서 수집: 증거의 모양 그대로

단서는 탐정 게임처럼 얻는 순간이 보이고, 카드는 그 증거의 모양을 띠게 바꿨습니다. PRD는 장치 옆 말풍선 카드에서 [단서 수집]을 누르는 방식이었습니다. 지금은 도장이 찍히는 획득 장면 뒤 카드가 수집함으로 들어갑니다.

- 실험 결과: 장치 사진 카드
- 현미경 결과: 관찰 슬라이드 카드("산소 그대로 · 150.0 g 그대로", "산소가 붙을수록 2.0 → 2.5 g")
- 실험 노트 조건: 찢은 쪽지 카드

PRD의 동그란 모형 카드 M1(원자는 새로 생기거나 없어지지 않는다)과 M2(저울은 점선 안만 잰다)는 없앴습니다. 교수의 원리를 카드로 쥐여 주지 않고, 학생이 현미경에서 직접 본 장면을 근거로 쓰게 하려는 것입니다. 수집함은 카드가 늘어도 줄어들지 않고 좌우로 넘깁니다.

## 반박: 고르기 문제에서 교수 말 깨기로

가장 크게 바뀐 단계입니다. PRD는 미니 퀘스트 세 개로, Q1 예측 카드와 빈칸 고르기, Q2 고르기와 짧은 서술, Q3 한 문장 서술을 차례로 받았습니다. 지금은 세 라운드 모두 같은 틀을 따릅니다.

1. 교수가 "혹시 ~건 아니겠나?" 꼴의 추측을 두 가지 던집니다.
2. 학생이 그 말의 틀린 부분에 단서 카드를 끌어다 놓아 반박합니다.
3. 교수가 방금 본 장면에 붙인 구체적인 질문을 하나 합니다.
4. 학생이 시작어가 주어진 한 줄로 답하고, 통과하면 결론 카드가 생깁니다.

| 라운드 | 교수의 추측 | 반박에 쓰는 단서 | 이어지는 질문 (시작어) |
| --- | --- | --- | --- |
| 1 (Q1, W2a) | 스스로 무거워진 건 아니겠나? / 불꽃의 열이 무게를 더한 건 아닐까? | 실험 B 사진, 막힘 슬라이드 | 불이 붙는 동안 플라스크 속 산소는 어디로 갔나? ("산소는") |
| 2 (Q2, W1b) | 산소는 기체라 무게가 없는 건 아닐까? / 강철솜 안에서 생긴 건 아니겠나? | 열림 슬라이드 | 그 산소들은 처음에 어디에 있었나? ("그 산소는") |
| 3 (Q3, W2b) | 새 물질이 생겼으니 질량도 새로 생긴 건 아닐까? | 막힘 슬라이드, 실험 B 사진 | 늘어난 0.5 g은 무엇의 무게인가? ("늘어난 0.5 g은") |

Q1 예측 카드와 Q1·Q2의 고르기 칸은 빠졌습니다. 세 번째 라운드에는 "산화 철이라는 새 물질이 생긴 건가?"라는 맞는 추측을 섞어, 모든 말을 반박하지 않고 골라 보게 했습니다. 교수 말투는 PRD의 단정적인 반박("왜 꼭 무언가 붙었다는 뜻이지?")에서 추측하는 질문으로 바꿨습니다. 교수가 갑자기 틀린 말을 하는 것이 어색하다는 피드백을 반영한 것입니다.

## 현미경: 직접 조작과 숫자 위치

현미경 안에서도 탐색과 같은 조작을 씁니다. PRD는 [불 붙이기]를 누르면 산소가 2초 동안 옮겨 붙는 구성이었습니다. 지금은 불꽃 막대를 대고 있거나 집게를 물려 둔 동안만 산소 분자가 하나씩 붙습니다. 마개를 눌러 막힘과 열림을 바꾸는 방식은 PRD와 같습니다.

- 원자 수: PRD의 철 6·산소 6에서 철 6·산소 10(산소 분자 5쌍)으로 바꿨습니다. 산소와 질소는 두 원자가 붙은 쌍으로 그리고, 쌍째 날아와 붙습니다.
- 저울 숫자: 화면 아래 따로 두지 않고 그림 속 저울 몸체 위에 겹쳐, 산소가 붙는 접시 바로 아래에서 바뀝니다. 바뀔 때마다 숫자가 살짝 커졌다 돌아오고, 불꽃 막대에 가려지지 않습니다.
- 대사: 원자 개수와 무게를 잇는 말을 모두 뺐습니다. PRD의 "점선 안 산소 6개는 저울에 안 잡히나?", "원자 수가 그대로였는데"가 여기에 해당합니다. 모형의 개수가 실제 무게처럼 읽히는 오해를 막기 위해서입니다. 같은 이유로 산소 하나가 붙을 때마다 "+0.1 g"을 띄우는 효과도 넣지 않았습니다.

## 화면 안내와 배치

설명하는 화면 글은 모두 빼고, 눌러야 할 물건 자체가 눈길을 끄도록 바꿨습니다. PRD는 네 구역 가운데 하나로 왼쪽 위 퀘스트 쪽지를 두었습니다. 안내는 깜빡임 3번, 10초 뒤 동사 칩("눌러 보기"), 30초 뒤 회색 힌트 줄 순서였습니다. 지금은 쪽지, 동사 칩, 힌트 줄이 모두 없습니다.

- 꼭 해야 할 조작 대상(불꽃 막대, 집게, 마개, 현미경)은 깜빡인 뒤 둘레에 별이 반짝입니다.
- 오래 멈춰 있으면 20초마다 교수가 한마디 합니다.
- 반박 라운드에서는 수집함 카드들이 차례로 들썩여 카드를 끌어 오라는 신호를 줍니다. 정답 카드만 따로 강조하지는 않습니다.

교수는 PRD가 정한 "칠판 옆 의자" 자리로 돌아와, 말풍선 바로 아래 책상 뒤에 앉아 있습니다. 다만 답하는 칸은 PRD의 "말풍선 바로 아래"가 아니라 교수 아래 책상 쪽에 열립니다. 교수가 올라오면서 답하는 칸이 얼굴을 가리게 되었기 때문입니다. 교수 대사는 "까닭 하나, 근거 카드 두 장" 같은 안내문투 대신 "하나 골라 주게"처럼 사람의 말투로 바꿨습니다.

## 결론 합치기

막대 그림과 요약 한 줄 대신, 두 실험의 작은 장면이 나란히 움직입니다. PRD는 결론 카드 ①·③을 올리면 질량 막대 두 개를 그리고, 아래에 "막으면 안에서 옮겨 갈 뿐 · 열면 밖에서 들어와 더해진다"를 붙였습니다.

- 막힌 쪽: 산소 분자가 플라스크 안에서 철로 옮겨 가도 저울은 150.0 g 그대로입니다.
- 열린 쪽: 접시 밖 산소 분자가 날아와 붙으며 2.0 g에서 2.5 g으로 올라갑니다.

요약 한 줄은 없앴습니다. 잠깐 떴다가 바로 지나가 읽기 어렵고, 학생이 써야 할 결론을 대신 말해 주기 때문입니다. 대신 두 장면을 학생이 탭할 때까지 칠판에 남겨 둡니다.

## 변론: 용어 대신 분필 글씨

카드 분류 칸에서 C·D·W라는 말을 걷어 냈습니다. PRD의 "주장(C) / 증거(D) / 연결(W)"은 "그래서 일어난 일 / 실험과 현미경에서 본 것 / 그게 뜻하는 것"으로 바뀌었습니다. 강의 노트 힌트의 줄 이름도 같은 말로 맞추었습니다.

분류할 카드 8장 가운데 모형 카드 두 장의 자리에는 현미경 관찰 슬라이드 두 장이 들어갔습니다. 나머지는 실험 A·B 결과, 결론 ①②③, 처음 고른 주장으로 PRD와 같습니다.

PRD에 없던 단계로, 최종 답을 내기 직전에 "내가 이 답에서 무엇을 물을 것 같나?"를 학생이 먼저 고릅니다. 학생이 고른 빈 곳과 실제 빠진 곳이 같으면 교수가 "스스로 알고 있군"이라고 돌려주고, 다시 채워 쓰게 합니다. 자기 답의 빈 곳을 스스로 짚어 보게 하려는 장치입니다.

## 판정과 기록

현재는 보기용 시험판이라 키워드 판정과 브라우저 안 기록만 씁니다. PRD는 LLM 판정과 키워드 판정, 팀 시트 저장, 교사 히트맵을 포함했습니다. 테스트가 팀 기록을 어지럽히지 않도록 시트 연결을 끄고 히트맵은 뺐습니다. LLM 루브릭 판정은 실제로 연결할 때 마무리하기로 했습니다.

대신 키워드 판정을 보강했습니다.

- "결합하지 않았다"처럼 부정한 문장은 요소로 인정하지 않습니다.
- 산소와 0.5 g의 연결 같은 요소는 한 문장 안에 함께 있을 때만 인정합니다.
- "산소는 사라졌다", "바깥에서 들어오지 않았다"는 통과시키지 않습니다.

판정 회귀 테스트 12개가 모두 통과합니다. Codex 교차 검증에서 나온 지적 11개도 반영했습니다.

## 아직 PRD 수준에 못 미친 것

PRD가 11.10까지 필수(P0)로 잡은 항목 중 아래가 남아 있습니다.

- [ ] 팀 시트에 기록 저장(미션 ID로 구분)
- [ ] 교사 히트맵에 미션 02 요소 코드 열 추가
- [ ] LLM 루브릭 판정 연결(키워드 판정은 대체용으로 유지)
- [ ] 미션 01에 새 화면 규칙 적용 여부 결정

PRD의 수용 기준(3초 규칙, 10초 규칙, 9~15분 클리어 등)은 중학생 플레이테스트로 다시 확인해야 합니다. 플레이 링크와 Apps Script 연결 방법은 같은 폴더의 [브랜치 공유와 Apps Script 연결.md](%EB%B8%8C%EB%9E%9C%EC%B9%98%20%EA%B3%B5%EC%9C%A0%EC%99%80%20Apps%20Script%20%EC%97%B0%EA%B2%B0.md)에 있습니다.
