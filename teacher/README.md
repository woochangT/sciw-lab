# 미션 기록과 교사 화면

같은 스프레드시트의 `감자`, `강철솜`에 미션당 한 탭을 사용한다. 열은 `recordType`, `recordId`, `sessionId`, `classCode`, `studentNo`, `missionId`, `createdAt`, `updatedAt`, `payload` 순서다. 세션과 시도를 별도 행으로 저장하고 키는 유형+ID다. 기존 `Sessions`, `Attempts` 탭은 보존한다. 같은 학생이 여러 판을 한 기록과 시도 원문도 남긴다.

학생 기존 batch 프로토콜과 감자 클라이언트 URL은 유지한다. 이 저장소의 새로운 `apps-script/Code.gs`는 아직 배포되지 않았다. 현재 운영 배포가 가리키는 탭과 버전도 확인되지 않았다. 강철솜 클라이언트는 검증 전 로컬 모드다. 새 교사 화면은 기본 합성 예시이며 서버 주소를 비워 기본 차단한다. 외부에서 쉽게 추측할 수 없는 교사 키를 서버 Script Properties에 등록하고, 검증된 배포 주소를 `teacher/config.js`에 지정해야 서버 조회를 시도한다. 비밀 키는 정적 파일이나 URL에 넣지 않는다. GET 원문 조회는 새 버전에서 차단된다.

## 필수 보안 한계

제공된 시트는 링크를 아는 누구나 편집 가능한 상태로 확인되었다. 이 상태에서는 교사 API에 키를 붙여도 시트 자체에서 기록을 직접 읽거나 바꿀 수 있어 학생 데이터 보호가 되지 않는다. 운영 전 파일 공유 권한을 담당자가 직접 제한하고, 로그인 기반 교사 인증, 학생 쓰기 인증과 남용 방지, 서버 판정·입력 검증, 정보 보존·삭제 정책을 마련해야 한다. 기존 학생 batch 쓰기는 호환성을 위해 인증되지 않으며 학생 전송 판정은 검증되지 않은 참고 자료다. 비밀번호 공유 방식은 계정 인증을 대체하지 않는다. 이 코드만으로 운영을 승인할 수 없다.

## 전환 절차 — 아직 실행하지 않음

1. 원본 `Sessions`·`Attempts`와 두 미션 탭을 백업하고, 운영 중인 Apps Script 프로젝트와 배포 ID가 이 스프레드시트를 사용하는지 소유자가 확인한다. 시트 권한을 먼저 제한하고 적절한 접근 모델을 결정한다.
2. 학생 활동을 일시 중단하고 **구 배포가 쓰기를 더 이상 받지 않도록** 조정한다. 대기 큐를 확인한다. 두 배포가 동시에 쓰면 전환 이후 누락·충돌을 보장할 수 없다.
3. 소유자가 프로젝트에 코드를 검토·반영한 다음 `reconcileLegacy`를 한 번 실행한다. 원본은 수정하지 않고 ID별로 복사·갱신한다. 시각이 없거나 미션이 충돌한 기록에서 중단되면 수동 비교한다. 결과 행 수와 ID별 payload를 원본과 대조하고 별도 사본에서 재시도 중복 방지를 점검한다. 시트 편집자나 구 서버가 동시에 쓰는 동안은 안전한 전환을 보장하지 않는다.
4. 별도 테스트 배포 및 합성 시트에서 양 미션 쓰기·재시도·조회·오류·접근 차단을 검증한다. 이 코드의 대상 ID는 실제 시트로 고정되어 있으므로 **테스트 복사본에서만** 테스트 시트 ID로 바꾸고, 실제 학생 내용을 사용하지 않는다.
5. 교사 접근 키를 고엔트로피 난수로 생성해 SHA-256 해시만 Script Properties의 `TEACHER_ACCESS`에 등록한다. 예: `[{"classCode":"EXAMPLE","missionId":"m01","keySha256":"<64자리 해시>"}]`. 각 반·미션에 별도 키를 부여하고, 키를 비밀로 전달·회수한다. 키 생성이나 등록은 이번 작업에서 수행하지 않았다.
6. 소유자의 승인 아래에만 새 버전을 배포하고 대상 스프레드시트·버전·행 수·권한을 재확인한다. 검증된 URL을 교사 설정에 넣고, m02 지원이 확인된 후에만 그 학생 설정의 `API_URL`과 `M02_SERVER_VERIFIED`를 설정한다. 이전 미전송 큐 처리 및 실패 시 롤백 계획도 먼저 확인한다.

기존 배포가 살아 있다면 새 버전의 GET 차단은 기존 배포에 적용되지 않는다. 원본 탭과 미션 탭의 두 경로가 공존할 때 어느 쪽이 최신인지 판단해야 하며 자동 양방향 동기화는 제공하지 않는다.

## 테스트

`node --test teacher/tests/*.cjs '감자 삼투/web/tests/'*.cjs '강철솜 질량 보존/web/tests/'*.cjs`

합성 데이터 및 메모리 모의 시트를 사용한다. 실제 배포, Google Apps Script 리디렉션·인증, 실제 파일 또는 여러 기기 동작은 검증하지 않았다.
